# Kanimozhi Portfolio

A custom static portfolio website built from scratch for GitHub Pages.

## Before publishing
1. Open `index.html` and replace `your@email.com` with the professional email you want clients to use.
2. Review the project titles/descriptions in `script.js`.
3. Keep the `assets` folder beside `index.html`, `style.css`, and `script.js`.

## GitHub Pages
Create a GitHub repository, upload the contents of this folder, then go to **Settings → Pages** and choose **Deploy from a branch**, selecting the `main` branch and `/root` folder.

The site is static: no server, database, paid hosting, or framework is required.


## Interaction details
The site includes a restrained Work dropdown, hover/touch-friendly media highlights, image/video sheen, project focus states, scroll reveals, and modal entrance animations. Animations respect `prefers-reduced-motion`.
